# Documentation versions

The site shows the documentation of the latest version by default. Select another version in the version menu of the navigation bar.

| Version | Package | Namespace | Last release | Documentation |
| --- | --- | --- | --- | --- |
| 4.x (latest) | `oralunal/laravel-clickhouse` | `Oralunal\LaravelClickHouse\` | 4.0.0 | [4.x](/getting-started/introduction) |
| 3.x | `oralunal/laravel-clickhouse` | `Oralunal\LaravelClickHouse\` | 3.0.0 | [3.x](/3.x/getting-started/introduction) |
| 2.x | `oralunal/phpclickhouse-laravel` | `PhpClickHouseLaravel\` | 2.0.2 | [2.x](/2.x/getting-started/introduction) |
| 1.x | `oralunal/phpclickhouse-laravel` | `PhpClickHouseLaravel\`, `Tinderbox\ClickhouseBuilder\`, `PhpClickHouseSchemaBuilder\` | 1.5.0 | [1.x](/1.x/getting-started/introduction) |

- The documentation of an earlier version describes the last release of that version. It comes from the README and the changelog of that release.
- Each page of an earlier version shows a notice with a link to the latest version.
- The search finds pages of the version that you read.

To upgrade from an earlier version, see [Upgrade](/getting-started/upgrading).
